Climbing Stairs
class Solution:
    def climbStairs(self, n: int) -> int:
        memo = {1:1, 2:2}
        def f(n):
            if n in memo:
                return memo[n]
            else:
                memo[n] = f(n-2) + f(n-1)
            return memo[n]
        return f(n)

    Инициализация словаря мемоизации:

        Создаем словарь memo для хранения количества способов подняться на i ступенек для конкретных значений i.

        Инициализируем базовыми случаями:

            memo[1] = 1 (1 способ подняться на 1 ступеньку: один шаг на 1 ступень)

            memo[2] = 2 (2 способа подняться на 2 ступеньки: два шага по 1 ступеньке или один шаг на 2 ступеньки)

    Определение рекурсивной функции:

        Определяем вспомогательную функцию f(n), которая вычисляет количество способов подняться на n ступенек:

            Проверка базового случая: Если n есть в memo, возвращаем сохраненное значение memo[n]. Это позволяет избежать перевычислений для уже решенных подзадач.

            Рекурсивный случай: Если n нет в memo, вычисляем количество способов подняться на n ступенек как сумму способов подняться на:

                n-2 ступенек (затем шаг на 2 ступеньки)

                n-1 ступенек (затем шаг на 1 ступеньку)

            Сохраняем результат в memo[n] как f(n-2) + f(n-1) и возвращаем его.

    Выполнение и возврат результата:

        Вызываем f(n) с входным значением n и возвращаем результат, который представляет общее количество различных способов подняться на n ступенек.
        Time: O(n)
	    Space: O(n)
