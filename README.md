Climbing Stairs

class Solution:
    def climbStairs(self, n: int) -> int:
        memo = {1:1, 2:2}
        def f(n):
            if n in memo:
                return memo[n]
            else:
                memo[n] = f(n-2) + f(n-1)
            return memo[n]
        return f(n)

Методология решения задачи Climbing Stairs

Оптимальное решение с мемоизацией (Top-Down Dynamic Programming)

Основная идея:
Решение использует рекурсию с мемоизацией для избежания повторных вычислений. Количество способов подняться на n ступенек равно сумме способов подняться на (n-1) и (n-2) ступенек, что соответствует последовательности Фибоначчи.

Пошаговая методология:

    Инициализация словаря мемоизации:

        Создаем словарь memo для хранения количества способов подняться на i ступенек

        Инициализируем базовыми случаями:

            memo[1] = 1 (1 способ: один шаг на 1 ступень)

            memo[2] = 2 (2 способа: два шага по 1 ступеньке или один шаг на 2 ступеньки)

    Определение рекурсивной функции:

        Создаем вспомогательную функцию f(n), которая вычисляет количество способов подняться на n ступенек:

            Проверка базового случая: Если n есть в memo, возвращаем сохраненное значение memo[n]

            Рекурсивный случай: Если n нет в memo:

                Вычисляем memo[n] = f(n-2) + f(n-1) (сумма способов подняться на n-2 и n-1 ступенек)

                Сохраняем результат в словарь

            Возвращаем memo[n]

    Выполнение и возврат результата:

        Вызываем f(n) с входным значением n

        Возвращаем результат, который представляет общее количество различных способов подняться на n ступенек

Анализ сложности:

    Время: O(n) - каждый подproblem вычисляется только один раз благодаря мемоизации

    Память: O(n) - для хранения результатов в словаре и стека вызовов рекурсии

Почему это оптимальное решение:

    Избегает повторных вычислений: Мемоизация сохраняет результаты подзадач

    Естественная рекуррентность: Отражение математической природы задачи (числа Фибоначчи)

    Читаемость: Понятное рекурсивное определение

Альтернативные подходы:

    Bottom-Up DP: Итеративное заполнение массива снизу вверх

    Оптимизированное по памяти: Использование двух переменных вместо массива (O(1) памяти)


Jump Game II

class Solution:
	def jump(self, nums: List[int]) -> int:
		smallest = 0
		n = len(nums)
		end, far = 0, 0
		for i in range(n-1):
			far = max(far, i+nums[i])
			if i == end:
				smallest += 1
				end = far
		return smallest

Методология решения задачи Jump Game II

Оптимальное решение с жадным подходом (Greedy Algorithm)

Основная идея:
Решение использует жадный подход для достижения временной сложности O(n). Вместо исследования всех возможных прыжков, алгоритм отслеживает две ключевые точки: end (самый дальний индекс, достижимый за текущее количество прыжков) и far (самый дальний индекс, достижимый за один дополнительный прыжок).

Пошаговая методология:

    Инициализация:

        smallest = 0 - счетчик минимального количества прыжков

        n = len(nums) - длина массива

        end = 0 - граница текущего прыжка (самый дальний индекс, достижимый за текущее количество прыжков)

        far = 0 - максимальная достижимая позиция из всех рассмотренных индексов

    Проход по массиву:

        Итерируемся по индексам от 0 до n-2 (последний элемент не рассматриваем, так как мы уже достигли цели)

        Для каждого индекса i:

            Обновляем far: far = max(far, i + nums[i]) - обновляем максимальную достижимую позицию

            Проверяем границу: Если i == end, это означает, что мы достигли границы текущего прыжка

                Увеличиваем счетчик прыжков: smallest += 1

                Обновляем границу: end = far - устанавливаем новую границу для следующего прыжка

    Завершение:

        Возвращаем smallest - минимальное количество прыжков для достижения последнего элемента

Преимущества подхода:

    Эффективность: Каждый элемент обрабатывается один раз, временная сложность O(n)

    Память: Используется только O(1) дополнительной памяти

    Оптимальность: Всегда находит минимальное количество прыжков

Почему это оптимальное решение:

Жадный подход использует тот факт, что для минимизации количества прыжков мы всегда должны прыгать на максимально возможное расстояние в пределах текущей досягаемости. Это преобразует задачу в линейное сканирование и исключает экспоненциальное ветвление методов полного перебора.

Pascal's Triangle II

class Solution:
    def getRow(self, rowIndex: int) -> list[int]:
        row = [1] * (rowIndex + 1)
        
        
        for i in range(1, rowIndex):
            row[i] = row[i-1] * (rowIndex - i + 1) // i
        
        return row
    

Методология решения задачи Pascal's Triangle II

Оптимальное решение с комбинаторным подходом (Combinatorial Algorithm)

Основная идея:
Решение использует математические свойства биномиальных коэффициентов для достижения временной сложности O(n). Вместо построения всего треугольника Паскаля, алгоритм напрямую вычисляет нужную строку, используя рекуррентное соотношение между соседними элементами.

Пошаговая методология:

    Инициализация:

        row = [1] * (rowIndex + 1) - создаем массив результата, заполненный единицами (базовый случай)

        Это соответствует крайним элементам строки: C(n,0) = C(n,n) = 1

    Вычисление элементов:

        Итерируемся по индексам от 1 до rowIndex-1 (внутренние элементы строки)

        Для каждого индекса i:

            Обновляем значение: row[i] = row[i-1] * (rowIndex - i + 1) // i

            Эта формула основана на рекуррентном соотношении биномиальных коэффициентов

            Целочисленное деление гарантирует точность вычислений

    Завершение:

        Возвращаем row - полностью вычисленную строку треугольника Паскаля

Преимущества подхода:

    Эффективность: Каждый элемент вычисляется за O(1), общая сложность O(n)

    Память: Используется только O(n) памяти для хранения результата

    Точность: Целочисленные вычисления исключают ошибки округления

    Оптимальность: Прямое использование математических свойств задачи

Почему это оптимальное решение:

Комбинаторный подход использует тот факт, что элементы строки треугольника Паскаля представляют собой биномиальные коэффициенты, связанные рекуррентным соотношением. Это позволяет вычислять каждый следующий элемент на основе предыдущего, преобразуя задачу в линейное сканирование и исключая необходимость построения всего треугольника.

Best Time to Buy and Sell Stock

from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = float('inf')
        max_profit = 0        
        
        for price in prices:
            profit = price - min_price
            
            min_price = min(price, min_price)
            max_profit = max(profit, max_profit)
                
        return max_profit

Методология решения задачи Best Time to Buy and Sell Stock

Оптимальное решение с линейным сканированием (One-Pass Algorithm)

Основная идея:
Решение использует однопроходный подход для достижения временной сложности O(n). Вместо проверки всех возможных пар дней для покупки и продажи, алгоритм отслеживает минимальную цену покупки и вычисляет потенциальную прибыль на каждом шаге.

Пошаговая методология:

    Инициализация:

        min_price = float('inf') - устанавливаем минимальную цену в бесконечность (для корректного сравнения)

        max_profit = 0 - инициализируем максимальную прибыль нулем (минимально возможное значение)

    Линейное сканирование массива:

        Итерируемся по всем ценам в массиве от начала до конца

        Для каждой цены price:

            Обновляем минимальную цену: Если price < min_price, то min_price = price

                Это гарантирует, что мы всегда покупаем по самой низкой цене из увиденных

            Вычисляем текущую прибыль: profit = price - min_price

                Рассчитываем прибыль от продажи по текущей цене после покупки по минимальной

            Обновляем максимальную прибыль: Если profit > max_profit, то max_profit = profit

                Сохраняем наибольшую найденную прибыль

    Завершение:

        Возвращаем max_profit - максимальную возможную прибыль

Преимущества подхода:

    Эффективность: Каждый элемент обрабатывается один раз, временная сложность O(n)

    Память: Используется только O(1) дополнительной памяти

    Простота: Понятная и легко реализуемая логика

    Оптимальность: Гарантированно находит максимальную прибыль

Почему это оптимальное решение:

Однопроходный подход использует ключевое наблюдение: максимальная прибыль достигается при покупке по самой низкой цене до момента продажи. Отслеживая минимальную цену на каждом шаге и вычисляя потенциальную прибыль, мы исключаем необходимость проверки всех возможных пар дней, что преобразует задачу из O(n²) в O(n).
